# 5PM MSP v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship 5pmmsp.com v1 — a mobile-first, location-aware, SEO-strong Twin Cities happy hour finder on Cloudflare Workers + D1, in the approved "Bottle Cap" design.

**Architecture:** One Cloudflare Worker serves SSR HTML (home/neighborhood/bar pages), a compact `/api/bars.json` for client-side geolocation filtering, and Turnstile-gated POST endpoints writing to D1. Static assets (CSS, client JS, PWA bits) ship via Workers assets. All distance math happens on-device.

**Tech Stack:** Cloudflare Workers (plain JS ES modules, zero npm deps — hand-rolled router instead of Hono; same route architecture as spec, chosen so the build needs no npm-registry egress), D1 (SQLite), Leaflet via CDN on the map page only, `node:test` for unit tests, global wrangler for dev/deploy.

**Spec:** cos repo `docs/superpowers/specs/2026-07-13-5pmmsp-design.md` (PR #198). Design tokens + reference mockup: `a-bottlecap.html` (view publish `5pmmsp-design-options-5b8443`).

## Global Constraints

- Timezone: ALL happy-hour logic in `America/Chicago` via `Intl.DateTimeFormat` (DST-safe).
- HH windows: `dow_mask` bit 0=Mon…6=Sun; `start_min`/`end_min` minutes-since-midnight; `end_min < start_min` = spills past midnight.
- Location never sent to the server — geolocation + haversine are client-side only; say so in the UI.
- Design tokens (exact): night `#101B2D`, filament `#FFB84D`, cap-red `#C8322B`, enamel `#F4E9D8`, brew-green `#2E6B4F`, ink `#26221C`. Fonts: Big Shoulders Display / Archivo / IBM Plex Mono (Google Fonts).
- Verified badge (◆, brew-green) ONLY when `verified=1` with `last_verified` date; everything else shows "unverified".
- Turnstile on all POST forms; use test sitekey `1x00000000000000000000AA` until a real widget is created; secret via worker env.
- Copy: sentence case, plain verbs, no hype. Empty states always suggest the next action ("next up at 3 PM").
- Repo: `~/5pmmsp`, standalone git repo → GitHub `adamevers/5pmmsp`.
